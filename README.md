# LipatoS - Расход ячеек после броска

Модуль для **Foundry Virtual Tabletop** и системы **D&D 5e**, который откладывает расход ячейки заклинания у обычных игроков до фактического броска кубика.

Если игрок открыл окно использования заклинания, но закрыл его до броска, ячейка не расходуется. Раздел **«Расход»** в окне сотворения заклинания для игроков скрыт, а использование ячейки остаётся включённым автоматически.

## Версия

**1.0.0**

## Совместимость

- Foundry VTT: **14**
- D&D 5e: **6.0.0–6.0.3**

## Возможности

- скрывает у игроков раздел **«Расход»** в окне сотворения заклинания;
- автоматически оставляет включённым расход ячейки;
- сначала откатывает штатный расход ячейки D&D 5e;
- списывает ячейку только после состоявшегося броска;
- если бросок отменён или окно закрыто, ячейка не расходуется;
- поддерживает броски атаки, урона и другие броски D&D 5e через `postRollConfiguration`;
- для ГМ и Assistant GM ограничений нет.

## Установка

В Foundry VTT откройте **Add-on Modules → Install Module** и вставьте ссылку на манифест:

`https://raw.githubusercontent.com/Lipatosha/LipatoS-spell-slot-after-roll/main/module.json`
